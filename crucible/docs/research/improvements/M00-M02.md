# M0 core, M1 world, M2 actors: what other frameworks do better, ranked fixes (2026-10-11)

M0–M2 are well hardened. Most remaining gaps are scale and robustness, not missing abstractions.

## Structural violations

- **S1. The layering is broken, and the import linter can't see it.**
  - `world/world.py:32` imports `crucible.connectors.agent_events` (M1 → M3).
  - `actors/llm.py:279-282` imports `crucible.train.*` (M2 → M12).
  - `actors/rlm/manager.py:304-305` imports `crucible.accept` and `crucible.forge` (M2 → M9/M8).
  - The `layers` contract (`pyproject.toml:133-136`) lists only core / world / actors.
- **S2. No CI.** The M0 gate says "import-linter contracts active in CI", but there is no `.github/` and no test runs
  `lint-imports`.
- **S3. Provenance is optional.** `Store.put_doc(..., prov=None)`, the only caller passes none, and `SourceRef.hash` is
  optional.
- **S4. Rule 3 at risk.** The M2 ≤ 1% fabrication gate is counted by an LLM judge. The strict run gives 1.3%; it passes
  only after a verbatim-is-supported rule. This needs a human-labelled calibration set with reported agreement.
