## M10 runtime

**Bugs found:**
- **Harness exceptions are not contained.** `run.py:139` has no try/except around `harness.run`. An unclassified
  exception aborts the whole run through `asyncio.gather` and leaves the ledger op `reserved`.
- **No per-attempt deadline and no walltime drain.**
- **Retries are immediate.** No backoff, no run-wide budget, and the global semaphore is held across retries.
- **One global semaphore** covers both the agent and grading phases.
- **`run.json` has no pins** (versions, task digests, images), though the journal docstring promises "code/framework
  pins".
- **No process lock.** A second runner on the same `run_id` would steal the first one's in-flight attempts
  (`journal.py:98-107`).
- **Health stop rules are run-global only.**
- **No per-rollout structural quality checks.**
- **`over_uncertain_tolerance` is never called;** `release()` is unused.
- **Checkpoints carry no identity** (world-spec hash, code version, blob digests).
- **No host failover and no multi-host scheduling.**
- **Concurrent attempts sharing an LLM client were charged each other's spend.** Fixed 2026-10-11:
  `NativeHarness` now charges an attempt its own model calls (`tests/unit/test_runtime_cost.py`).
